# Calendar-news — Vercel edition

Готовое Flask-приложение для Vercel + Neon PostgreSQL.

## Архитектура

- **GitHub** — исходный код.
- **Vercel** — веб-приложение и Flask backend.
- **Neon PostgreSQL** — общая постоянная база данных.

Vercel официально поддерживает Flask как Python backend, а Neon доступен как Postgres-интеграция в Vercel Marketplace.

## 1. Загрузить проект в GitHub

Загрузите содержимое этого архива в:
`lesssovest/Calendar-news`

## 2. Создать проект в Vercel

1. Откройте Vercel.
2. `Add New → Project`.
3. Выберите GitHub и репозиторий `Calendar-news`.
4. Нажмите Deploy.

## 3. Подключить Neon

В Vercel откройте проект → Storage/Marketplace → Neon.
Создайте новую Neon database и подключите её к проекту.

Vercel/Neon выдаст переменную `DATABASE_URL`.

## 4. Добавить переменные окружения

В Vercel → Project → Settings → Environment Variables добавьте:

- `SECRET_KEY` — длинная случайная строка.
- `ADMIN_EMAIL` — ваш рабочий email администратора.
- `ADMIN_PASSWORD` — новый сильный пароль администратора.
- `ADMIN_NAME` — например `Calendar Admin`.
- `DATABASE_URL` — создаётся/добавляется при подключении Neon.

После изменения переменных сделайте Redeploy.

## 5. Первый вход

После первого запуска приложение автоматически создаст таблицы и команды.
Администратор создаётся только если заданы `ADMIN_EMAIL` и `ADMIN_PASSWORD`.

### Важно

Не используйте пароль из старой демо-версии.
Не храните `DATABASE_URL`, `SECRET_KEY` или пароль администратора в GitHub.

## 6. Что уже работает

- Пн/Пт — публикация разрешена.
- Вт/Ср/Чт — лучшие дни.
- Сб/Вс — заблокированы.
- Одна публикация на дату.
- Создание, перенос, редактирование, удаление.
- Важная публикация.
- Команды.
- Администратор и участники команд.
- История изменений.
- PostgreSQL.
- `/health` для проверки приложения.

## Ограничение текущей версии

Пользователи команд создаются через код/БД, а полноценное управление пользователями из админки ещё не добавлено. Для внутреннего MVP это нормально; следующим шагом можно добавить приглашения пользователей и/или корпоративный SSO.
